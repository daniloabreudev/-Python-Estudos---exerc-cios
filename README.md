# 🐍 Rotina de Estudos: Python & Programação Orientada a Objetos (POO)

Repositório criado para registrar minha evolução diária, exercícios e desafios práticos desenvolvidos durante os cursos de **Python** e **Python POO** do Curso em Vídeo (Gustavo Guanabara). 

O objetivo deste espaço é consolidar minha lógica de programação, documentar meu aprendizado prático e acompanhar meu progresso rumo ao desenvolvimento de soluções e sistemas computacionais mais robustos.

---

## 🚀 Tecnologias e Conceitos Estudados

*   **Lógica e Estrutura de Dados:** Variáveis, tipos primitivos, estruturas condicionais (`if/elif/else`) e estruturas de repetição (`while` e `for`).
*   **Coleções em Python:** Manipulação e uso prático de Listas, Tuplas e Dicionários.
*   **Modularização:** Criação de funções (`def`), tratamento de parâmetros e escopo de variáveis.
*   **Tratamento de Erros:** Controle de exceções com blocos `try/except` para garantir a resiliência do software.
*   **Programação Orientada a Objetos (POO):** 
    *   Abstração e Modelagem de Classes e Objetos.
    *   Métodos Construtores e Manipulação de Atributos (`self`).
    *   Encapsulamento (Atributos e métodos privados, Getters e Setters).
    *   Herança e Polimorfismo para reutilização e especialização de código.

---

## 📁 Estrutura do Repositório

O código está organizado de forma cronológica e por módulos para facilitar a consulta rápida:

*   `/Mundos/`: Desafios de lógica fundamental, estruturas de repetição e manipulação de dados nativos.
*   `/POO/`: Exercícios práticos aplicando os pilares da Orientação a Objetos (Classes, Herança, Encapsulamento).
